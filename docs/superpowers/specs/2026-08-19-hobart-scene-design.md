# 霍巴特程序化插画背景 — 设计文档

- **日期**:2026-08-19
- **状态**:已与需求方确认(提供参考插画;确认"程序化插画(推荐)"而非图片文件)
- **基线**:main @ 1917a11 之上的增量,分支 feature/hobart-scene

## 1. 需求

把 TV 背景从抽象楼群剪影升级为**参考插画风格的霍巴特全景**(平涂海报/动画电影风),用代码逐层绘制(非图片资源);**完整保留**现有时间引擎(真实日出日落驱动的时段推移、太阳/月亮/星星)与天气引擎(雨/雪/雷/风/雾/云量,Open-Meteo 实况)。程序化的优势必须兑现:夜晚窗灯逐扇点亮、水面反光随时段变化、船只轻摇。

## 2. 场景构图(参考插画的归一化映射,y 为屏高比例)

自后向前分层(每层独立纯函数绘制):

| 层 | 内容 | 纵向区间 |
|---|---|---|
| sky | 天空渐变 + 平涂风积云(白色扁平云簇、底部微暗) + 日/月/星(沿用现引擎) | 0 – 0.40 |
| mountain | 威灵顿山双段山脊(远脊偏紫灰、近脊带绿坡),山顶发射塔细节,山脚城郊亮色碎点房 + 雾霭带 | 0.08 – 0.42 |
| bridge | 塔斯曼桥(左侧 x 0.02–0.38):多组高桥墩 + 缓拱桥面,夜晚桥面路灯串 | y≈0.34–0.42 |
| city | 中景 CBD 带:左中棕色高层(参考图红棕大楼)、白/灰塔楼群、圆顶地标、砂岩乔治式建筑(山墙/钟楼),树冠团 | 0.38 – 0.58 |
| waterfront | 码头仓库带:红顶/绿顶大仓库、白色连排、栈桥,系泊游艇(桅杆线) | 0.54 – 0.70 |
| water | 港湾水面:平涂水色 + 横向浅色波纹条 + 建筑倒影(垂直拉伸暗色块)+ 太阳/月亮波光路径(沿用 glitter)+ 2–3 艘小船(轻微上下摇) | 0.60 – 0.80 |
| foreground | 前景屋顶群(山墙、烟囱、老虎窗)+ 深色树冠,画面底边收口 | 0.74 – 1.0 |

固定伪随机种子(mulberry32,延续现约定)生成细节(窗格、碎点房、桅杆、波纹),刷新不变形。

## 3. 画风规则

- **平涂**:每个物体 2–3 个色阶面(受光面/固有色/暗面),禁用物体内渐变(天空与水除外);极少量深色描线(仅关键轮廓,1px)。
- **日间基准色**(取自参考图):天空 #3E7BD0→#BBD9EF;山体 #6B5D75/#8B7A8D + 山坡绿 #5E7A4C;砂岩 #D9B97C/#C9A45F;仓库红顶 #A63B32、绿顶 #3E6B54、灰蓝顶 #8C9BA6;水 #3E6FA8/#5C8CC4;云 #F4F1E8。
- **时段变化**:现 KEYS 六关键帧扩展为**分层色组**(sky/far/mid/near/water/light 六组各自插值)——黄金时刻整城暖金、受光面转橙;日落天空橙红、山体剪影化;夜晚整体深蓝压暗、窗灯暖黄逐扇点亮(windowLit 系数沿用)、桥灯串亮起、船位灯、水面出现灯光竖向倒影;清晨冷粉。dim 压暗幕与可读性机制不变。
- **天气**:雨/雪/闪电/风/雾全部沿用现有粒子与序列逻辑,仅云的绘制换平涂风;阴天(cloudiness 高)整体去饱和的现逻辑保留。

## 4. 性能与结构

- **静态层离屏缓存**:sky 渐变、mountain、bridge、city、waterfront、foreground、水底色与倒影全部画入离屏 canvas,失效键 =(尺寸 × t 步进桶 0.015 × 云量档 × 4s 窗灯闪烁纪元)——与现机制同款;每帧仅绘制:贴缓存底图 → 日/月/星(闪烁)→ 云(慢移)→ 波光/波纹动画 → 船摇 → 天气粒子/闪电 → 压暗幕。
- **代码结构**:新目录 `src/lib/scene/hobart/`——`geometry.ts`(归一化坐标常量与公共类型)、每层一个文件导出 `drawX(ctx, w, h, sp, rng)`(sp = 分层调色结果 ScenePaint);`palette.ts` 扩展分层色组(现导出 API 保持兼容,phaseFromClock/fyLabel 等不动);`SkylineBackground.tsx` 改为装配器(组装层列表 + 缓存 + 动画循环 + 天气粒子,组件对外 API `{ weather, paused }` 不变,TvApp 零改动)。
- 粒子/DPR/隔帧/paused 约束全部沿用现值。

## 5. 验证

- 单元:geometry 纯函数与分层调色插值的边界用例;现有 palette/weather 测试保持绿(公共 API 兼容)。
- **视觉评审(硬门禁)**:e2e harness 截图矩阵——正午/黄金时刻/夜晚 × 晴/雨/雷,共 6+ 张;逐张目验:构图与参考图对应(山/桥/城/港/前景五要素齐)、平涂风格成立、夜晚窗灯与水面灯影出现、文字可读性不降。多评审员独立打分,不合格项迭代。
- 全量 vitest / `npm run build` / E2E 6 条全绿(canvas 仍 z-0 pointer-events-none,断言零影响)。

## 6. 非目标

图片资源文件;视差滚动;行人/车辆动画;季节变化;按 org 换城市;参考图的像素级复刻(目标是"同构图同画风的程序化再创作")。

## 7. 成功标准

TV 背景呈现可辨识的霍巴特全景插画(威灵顿山、塔斯曼桥、码头仓库、港湾帆船);时段推移连续自然,夜晚窗灯/桥灯/水面灯影真实点亮;天气特效照常;全部门禁绿。
